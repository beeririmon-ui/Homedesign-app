# Clay לסבב 2 של פריימי המגזין (הצעה 0.2)

השוואת clay לכל מה שסעיף 8 ב-`docs/proposals/house-framing.md` ומפתח `round_2` ב-`house-framing.json` מבקשים (‏master-designer, ‏2026-10-08). ‏Blender 4.2 (bpy מ-pip), ‏Cycles CPU, ‏seed 7, ‏2048×1152, ‏48 דגימות עם OIDN. ‏**0 קרדיטים של var2.** לא שיניתי שום מסמך מחייב (תוכנית הבית, ה-Bible, השלד, קבצי העמדות) ולא תיקנתי כשלים של ההצעה (`fix_policy`). איפה שההצעה לא נתנה מיקום, בחרתי בעצמי, וכל בחירה כזו מופיעה ב"החלטות" למטה.

## איך מריצים
```
python3 build_house.py --framing round2            # הכול: 6 פריימים, 4 picks מוארים, מעברים, דף השוואה
python3 build_house.py --framing K2-boy,B1         # פריימים נבחרים
python3 build_house.py --framing round2-lit        # H-B, C-B, W-A, MB-A עם תוספות S11/S12 ומנורות דולקות
python3 build_house.py --framing round2-trans --trans "T-LD''"   # דף מגע אחד
python3 build_house.py --framing round2-sheets     # רק all-round2.jpg וה-summary
```
הקוד נמצא ב-`framing_r2.py`. ‏`framing.py` רק מעביר אליו כשהבחירה היא של סבב 2; חלופות סבב 1 (H-A עד B-B) והבנייה בלי הדגל לא השתנו. ‏`FRAMING_R2_OUT=<dir>` כותב לתיקייה אחרת (לבדיקות).

**סצנה אחת לכל סבב 2:** תוכנית 1.0, ועליה ה-deltas של ה-picks מסבב 1 (H-B, ‏C-B, ‏W-A, ‏MB-A, בדיוק כמו `framing.py`), הגאומטריה של סבב 2 בילדים, במקלחת ובמטבח (G-K1r2…G-D4), ותוספות S11/S12 בכניסה, במסדרון, בעבודה ובהורים. כך המעברים עוברים בבית אחד עקבי.
