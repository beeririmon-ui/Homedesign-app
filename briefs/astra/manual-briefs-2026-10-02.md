# משימות ל-Astra להרצה ידנית ב-ChatGPT (2026-10-02)

מעתיקים כל בלוק כמו שהוא ל-ChatGPT, ומדביקים את התשובה בשיחה עם המנהל. התשובות נשמרות ב-`briefs/astra/` ונבדקות על ידי master-designer.

## 1. מוצרים לעמדות הריקות (עם גלישה באינטרנט)
```
אני בונה חנות דרופשיפינג לעיצוב הבית בישראל, בסגנון נורדי, במיצוב פרימיום נגיש. ב-CJ Dropshipping לא מצאתי מוצרים לעמדות האלה. מצא לי מוצרים אמיתיים ב-AliExpress (או ב-Temu, Alibaba או ספקי דרופשיפינג אחרים):
1. תמונה ממוסגרת (framed-art): זוג 70×100 לאורך, שלישייה 50×70, או בודדת 100×150. מופשט רך, רישום קו או נוף ערפילי, עם אלמנט פחם. מסגרת אלון בהיר או שחור מט, פספרטו לבן חם. בלי טקסט, בלי אנשים, בלי זהב ובלי העתקים של אמנים מוכרים. מילות חיפוש: minimalist line art framed set of 2, abstract neutral framed print 70x100 oak frame, japandi wall art set charcoal beige.
2. מנורת קיר (wall-sconce): זרוע ישרה או מתקפלת, אהיל תוף או קונוס מבד, plug-in עם כבל, CE, 220–240V, תקע EU. פלטה מאלון או שחור מט. אהיל ⌀16–24. לא העתק של Lampe Gras.
3. מנורה תלויה (pendant): אהיל פשתן או נייר אורז, תוף, פעמון רך או פנס שטוח, תחתית סגורה או מפזר. CE, 220–240V, ⌀40–50. לא העתק של Noguchi, Akari, PH או Le Klint.
4. וילונות: 2 פאנלים, פשתן או מראה פשתן חצי-שקוף, תלייה בקפלי גל, בקפלי צביטה או בלולאות אחוריות (לא עיניות ולא לולאות קדמיות), כל פאנל 130–150 × 250–260 ס"מ. לבן חם, שיבולת שועל או אפור ערפל.
5. שטיח: 200×300 בערך. צמר שטוח, ברבר בהיר, או יוטה, קש ים או סיסל טבעי. שמנת בהירה, או אפור ערפל עם קווים דקים בפחם.

לכל עמדה תן 3–5 מוצרים. לכל מוצר: קישור מלא לדף המוצר, שם, מחיר, האם יש משלוח לישראל (רק אם ראית את זה בדף), מספר הזמנות או ביקורות, מידות וחומר. העדף מוצרים סדרתיים עם הרבה הזמנות. אל תמציא קישורים, ומה שלא ראית בדף סמן "לא אומת". ענה בעברית בטבלה לכל עמדה.
```

## 2. שם למותג
```
אני מקים מותג ישראלי לעיצוב הבית, במיצוב פרימיום נגיש. באתר הלקוח "נכנס" לבית ריאליסטי, עובר בין חדרים, נוגע במוצרים ובוחר וריאציות. אותו בית מולבש בכמה סגנונות: נורדי, בוהו ומודרני חם. השמות שכבר הוצעו (ולא נבחרו): ביתה, סף, חומר, תבנית, מעונה, חדר/HEDER (נדחה, נשמע סתמי), I design.
תן 15 שמות חדשים: 5 בעברית, 5 באנגלית, ו-5 שעובדים בשתי השפות. לכל שם: משמעות, למה הוא מתאים, הגייה בעברית ובאנגלית, סיכון (שם תפוס, משמעות שלילית, קושי באיות), והאם הדומיין ‎.co.il או ‎.com נראה פנוי (בדוק אם אתה יכול; אחרת כתוב "לא נבדק"). בסוף: 3 המועדפים שלך ולמה. ענה בעברית.
```

## 3. כלכלה: מכס, מע"מ ותמחור לישראל
```
אני חנות דרופשיפינג בישראל לעיצוב הבית. המוצרים נשלחים מסין (CJ Dropshipping) ישירות ללקוח פרטי, במשלוח חסכוני של 12–50 ימים או מהיר של 9–27 ימים.
1. מה הכללים העדכניים בישראל למכס ולמע"מ על חבילה אישית מחו"ל: הפטור, הסכומים ומי משלם? תן מקורות רשמיים (רשות המסים) עם תאריך.
2. האם יש הבדל בין מוצר טקסטיל, קרמיקה וגוף תאורה (למשל אישור מכון התקנים למוצרי חשמל)?
3. איך מתמחרים נכון: נוסחה מומלצת למחיר לצרכן בש"ח מתוך עלות מוצר ומשלוח בדולרים, כולל מע"מ, עמלת סליקה, החזרות ומרווח של 2.5–3.5 בשיטת פרימיום נגיש.
4. דוגמה מחושבת: כרית במחיר $3 + $9 משלוח, אגרטל במחיר $10 + $27 משלוח, ושמיכה במחיר $12 + $25 משלוח.
ענה בעברית. מה שלא בטוח, סמן "לא בטוח" והמלץ לבדוק מול רואה חשבון.
```

## 4. פנייה לספקים ישראליים (שטיחים ווילונות)
```
כתוב לי הודעת פנייה קצרה ומקצועית בעברית לספק או חנות ישראלית של שטיחים ווילונות (למשל NOOL או הנסיכה אונליין). אני מקים מותג אונליין לעיצוב הבית בסגנון נורדי ומציע שיתוף פעולה בשיטת דרופשיפינג: הלקוח מזמין אצלי, ואתם שולחים ישירות אליו בשמי (בלי חשבונית או מחיר באריזה).
השאלות שההודעה צריכה לשאול:
- מחיר סיטונאי או מחיר לחנויות
- האם אפשר משלוח ישיר ללקוח הסופי, באיזו עלות ותוך כמה זמן
- האם יש קטלוג או קובץ מוצרים עם תמונות ומידות (CSV או API)
- מלאי וזמינות
- מדיניות החזרות
- האם מותר להשתמש בתמונות שלהם
- מינימום הזמנה
תן שתי גרסאות: אחת למייל ואחת קצרה לוואטסאפ.
```
