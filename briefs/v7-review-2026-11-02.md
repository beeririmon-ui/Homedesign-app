## The task
1. **A verdict on each master and each pose:**
   - **keep for the test**, **fix** (what, and how), or **retake**;
   - is it "wow" at design-magazine level (א.1)? If not, what exactly holds it back: composition, light, styling density, materials, emptiness, generic catalogue feel;
   - does it break the Bible (forbidden list, palette, light rules, density)?
   - is it fit for the transitions?
2. **The four broken locks (M0, MB0, H0, W0):** propose a fix method for each.
   - **(a)** local inpainting or a masked edit on the drifted area only;
   - **(b)** a recipe change: crop references instead of whole masters (render-agent's lesson), a stronger clay-lock paragraph, a different reference set;
   - **(c)** accept for the test with a note, if the drift doesn't matter for the walk-through. Product layers are a Gate 2 matter, not this test.

   M0 is the hero frame, the focus-mode test runs on it, and the sofa width is a fidelity question (נאמנות למוצר קודמת ליופי). Treat it first.
3. **The "most spectacular" gap:** list the 3–5 changes, across the set, that would lift it the most toward magazine level within the budget. Examples: corridor C0 and work room W0 read sparse; the snow in K-boy.
4. **A ranked retake list within 3,600 tokens:**
   - frame, method, expected gain, cost;
   - the exact new prompt for each retake, written as a new file next to the old one (`*-v7-r3.txt`, or `pose-*-v7-r2.txt`).
