# תוכנית תנועה: סרטון אחד, הרבה שוטים

> החלטת משתמש (סוכמה בשיחה אחרת ב-2026-09-28, ונכתבה כאן ב-2026-09-29). **טיוטה.** השינוי ב-`docs/skeleton-spec.md` ייכתב רק אחרי שבדיקת הרינדור תאושר.

## הרעיון
לא מייצרים סרטון נפרד לכל מעבר, לכל כניסה למוצר ולכל תצוגה בגלגל. במקום זה:
1. מרנדרים ב-var2 **סרטון אחד לכל מסלול** ומחלצים ממנו פריימים.
   - מסלול יכול להיות כניסה לחדר (מהכניסה לסלון), או התקרבות למוצר (מהתצוגה הרחבה לתקריב של עמדה).
2. **מעבר:** מנגנים את הפריימים באתר כרצף. הגלילה או הלחיצה מזיזה אותם קדימה ואחורה, ולא סרטון שמתנגן.
3. **כניסה למוצר:** הפריימים האחרונים במסלול ההתקרבות הם שוטים סטילס בקלוז-אפ של העמדה. משתמשים בהם כרקע לדף המוצר וכרקע לגלגל, בלי סרטון או רינדור נוסף.
4. **וריאציות:** בכל שוט רק שכבת המוצר מתחלפת. הרקע, הצל והאור נשארים מהשוט.

## למה
- **חיסכון:** סרטון אחד נותן גם את המעבר, גם את התקריב וגם את רקע הגלגל, וזה חוסך קרדיטים.
- **המשכיות:** הכל יוצא מאותו רינדור, ולכן אין "קפיצה" בין התצוגה הרחבה לתקריב.
- **שליטה בקצב:** הפריימים ביד שלנו, ואפשר לעצור, לחזור אחורה ולגלול.
