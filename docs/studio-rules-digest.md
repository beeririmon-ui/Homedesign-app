## ח. אבטחה
1. מפתחות API רק במשתני סביבה שהמשתמש מגדיר. אף פעם לא בריפו ולא בצ'אט.
2. סריקת סודות לפני כל commit.
3. **קוד ההרשאה של AliExpress בסשן ענן (2026-10-17, המשתמש):** "נעשה את התהליך עם הזנת הכתובת בדפדפן... תני לי את הכתובת ואחזיר לך את הלינק". מותר שהמשתמש ידביק בצ'אט את כתובת החזרה (‏127.0.0.1/callback?code=...). ה-code חד-פעמי, פג תוך דקות, ולא שווה כלום בלי ה-App Secret. מחליפים אותו מיד בטוקן (`auth.py code`), והטוקן נשמר רק ב-~/.cache/ae. המפתחות עצמם (App Key ו-App Secret) נשארים רק במשתני הסביבה, ולא עוברים בצ'אט.
