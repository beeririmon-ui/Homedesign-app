## 1. התשובה בקצרה

**אין אגרגטור שמרכז את AliExpress ועוד הרבה אתרים וגם פותח לנו API או פיד.** שני הכלים שבאמת מייבאים מהרבה אתרים, AutoDS (29 מקורות) ו-Importify (25+), הם תוספי דפדפן שדוחפים מוצרים לחנות Shopify/Wix/Woo. אין להם API, אין ייצוא, ורוב המקורות ה"נוספים" שלהם (Amazon, Walmart, Costco, Home Depot, Target, Lowe's) הם קמעונאים אמריקאים שלא שולחים לישראל. Temu ו-Shein לא מפעילים תוכנית דרופשיפינג או API רשמיים (מקורות משניים בלבד). לכן "hub אחד" אפשרי רק דרך **גשר**: חנות-מחסן זולה שהכלים דוחפים אליה ואנחנו קוראים ממנה.

### 3.2 WooCommerce כמחסן נתונים (מומלץ אם רוצים גשר)
- **מה זה:** אתר WordPress פרטי (סיסמה, noindex), רק עם WooCommerce. AutoDS, Importify, DSers, Syncee, Spocket, Doba, Wholesale2B, Inventory Source, AppScenic, HyperSKU ו-EPROLO כולם תומכים ב-WooCommerce (Zendrop ו-Modalyst לא).
- **איך קוראים:** WooCommerce REST API v3 (`/wp-json/wc/v3/products`, מפתח צרכן, אומת בתיעוד הרשמי). תוכנה חופשית, בלי תנאי API של צד שלישי על הנתונים שלנו.
- **הזמנות:** כדי שהכלי ימלא אוטומטית, ה-Worker שלנו יוצר את ההזמנה ב-Woo דרך ה-API (`POST /orders`), והכלי אוסף אותה כמו כל הזמנת Woo. **לא אומת** שהכלים אוספים הזמנות שנוצרו ב-API ולא בקופה; לבדוק עם הזמנת ניסיון.
- **עלות:** אחסון WordPress (לא אומת, סדר גודל $5–15 לחודש) + כלי הייבוא. **סה"כ כ-$20–65 לחודש.**
- **יתרונות:** לא נוגע ב-T1 (החנות שלנו נשארת החנות; Woo הוא מסד נתונים עם API). בלי עמלת פלטפורמה. אפשר לחבר כמה כלים לאותו מחסן.
- **חסרונות:** תחזוקת WordPress (עדכונים, אבטחה), עוד רכיב בצנרת, ותלות בתוספי Chrome של הכלים. התמונות מגיעות כקישורים לאתרי המקור, עם אותו "לא מוגדר" בזכויות.
- **Wix** כחלופה: Importify, AutoDS, DSers, Zendrop, Modalyst, Syncee ו-Spocket תומכים ב-Wix, אבל ה-API של Wix Stores לא נבדק כאן (הדף החזיר 404) ו-Wix דורש תוכנית בתשלום. **לא אומת.**

### 3.3 מה הגשר נותן ומה לא
נותן: את 29 המקורות של AutoDS או 25+ של Importify בלחיצה, ו"מצא זול יותר" אצלם. לא נותן: API של המקורות עצמם (הכלים מגרדים אותם בדפדפן של המשתמש; זה הסיכון המשפטי שלהם, לא שלנו, אבל זכויות התמונה נשארות לא מוגדרות), משלוח לישראל מהקמעונאים האמריקאים, ואמינות ספק (Temu/Shein בלי תוכנית רשמית).

## 4. הנתיב המומלץ

1. **לא קונים "ספק-על" עכשיו.** ממשיכים עם AC2 (AliExpress API) ו-AC1 (CJ Sourcing), שמכסים את המקור הגדול ביותר ישירות וחינם.
2. **המשתמש פותח Zendrop חינם ומחבר את ה-MCP** (Customize > Connectors > Add custom connector > שם "Zendrop MCP", כתובת `https://app.zendrop.com/mcp/v1` בדיוק > Connect > אישור). בסשן חדש אנחנו בודקים: חיפוש "linen cushion cover", פרטי מוצר, והערכת משלוח ל-IL. אם עובד בלי חנות: Zendrop נכנס כמקור שני ל-`scripts/sourcing_common.py` (מקור "zendrop", דרך MCP). אם לא: סוגרים.
3. **DSers Advanced** נשאר כמו ב-AC4 ("אחרי AliExpress"). אותה בדיקה: האם ה-MCP מחפש בלי חנות.
4. **HyperSKU ו-EPROLO:** המשתמש פותח חשבון חינם בשניהם ומבקש גישת API מנציג החשבון (EPROLO: הודעה בצ'אט בדשבורד; HyperSKU: דרך תמיכה). שולחים לנו רק את קובץ התיעוד, לא מפתחות. בודקים בתיעוד: חיפוש, פרטי מוצר, תמונות, מחיר משלוח לישראל. מפתחות רק ב-`HYPERSKU_API_KEY` / `EPROLO_API_KEY` בהגדרות הסביבה.
5. **גשר Woo רק אם המשתמש רוצה את AutoDS/Importify בכל מחיר:** הוא פותח אחסון WordPress + WooCommerce (אתר פרטי), מתקין AutoDS (ניסיון $0.99) או Importify (14.95), ומייצר מפתח REST לקריאה בלבד ב-WooCommerce > Settings > Advanced > REST API. אנחנו בונים `scripts/woo_hub.py` (search/product/freight לפי אותו CLI של 2.3 במסמך הקודם) ומסמנים `supplier` לפי המקור שהכלי רשם.
6. **לא לעשות:** Wholesale2B, Doba, Inventory Source (לא שולחים לישראל או יקרים), Temu/Shein (בלי תוכנית רשמית), scrapers ב-RapidAPI/Apify.

## 5. מה לא אומת וחשוב
- **Zendrop MCP בלי חנות מחוברת:** לא כתוב. ה-FAQ מזכיר "ensure store connection" רק בפתרון תקלות. הבדיקה בסעיף 4.2 תענה.
- **DSers MCP בלי חנות:** לא כתוב. Temu ב-DSers: לא בטקסט.
- **HyperSKU / EPROLO לישראל:** אין טבלת מדינות. EPROLO מזכיר "Middle East" בקבוצת החזרים (דף מ-2020).
- **AutoDS מחירי תוכניות:** הדף הרשמי מציג "$__"; המספרים ממקור משני.
- **Importify "ישראלית":** הישות החוקית היא Importify Limited בהונג קונג. ייתכן שהצוות בישראל, לא אומת.
- **Shopify Agentic ‏($0):** לא ידוע אם פותח API; לא לבנות עליו.
- **Banggood Open Platform:** לא נגיש מהקונטיינר. אם המשתמש רוצה, הוא בודק ב-open.banggood.com מהדפדפן שלו.
