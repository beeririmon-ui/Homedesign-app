1. ממלאים את כל ה-[סוגריים] בהודעה. שם המותג עוד לא נקבע (ז.9): משתמשים בשם העוסק או "חנות בהקמה".
2. שולחים בסדר: הנסיכה ו-Bloomingville קודם (הכי חזקים), אחר כך BigBuy ו-NOOL. Syncee ו-Yakkyofy הם הרשמה ובדיקה עצמית, אפשר במקביל. ריהוט (שורות 7–22, תבנית אחת ב-furniture-il.md): קודם חלומות, עמינח, יראון, עצמל'ה ו-HOMAX; השאר בסבב שני.
3. מעדכנים את עמודת הסטטוס כאן, עם תאריך.
4. **כשמגיעה תשובה:** מדביקים אותה למנהל בשיחה (או שומרים ב-`docs/suppliers/outreach/replies/<supplier-id>-<date>.md`, בלי פרטים אישיים מעבר לשם איש הקשר). המנהל מעדכן את `data/suppliers/directory.json` ואת לוח הסטטוס, ומפעיל את sourcing-agent.
5. אין מענה תוך 5 ימי עסקים → תזכורת אחת קצרה, או טלפון לספקים הישראליים.

## כללים לכל התשובות
- **לא מתחייבים** להזמנה, מינימום או מנוי בתשובה הראשונה. כל תשלום → שאלה בסטודיו.
- **תקנים:** S2 — מידע בלבד. מוצרי ילדים עדיין דורשים ת"י 562 / EN71 (ד.4, D9). לתאורה: הסתירה בין S2 לבין דרישת ה-CE בבריף המותג פתוחה לבירור.
- **מחיר:** כל מחיר שמתקבל נבדק מול יעד העלות בקובץ הספק (נוסחת הסטודיו, `data/economics/market-prices.md` §3).
- **לא פונים** בשלב הזה לקבוצת כרמל (הערה רגישה בספרייה) ולא לספקי הדפס לפי הזמנה (S5).
