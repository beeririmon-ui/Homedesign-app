## מה הבעלים רואה, לפי הסדר
1. **הדלת (זמנית, בקוד).** קיר טיח (‎#ECE5DA), ובו פתח מעוגל עם קו אגוז. בתוך הפתח רואים את הסלון הריק האמיתי.
   - **במסך רחב:** הפתח על השליש השמאלי, מול החלון, והמילים לצידו.
   - **בטלפון:** הפתח באמצע, והמצלמה מופנית אל החלון.
   - **המילים:** "סיור בבית", "הבית המודרני החם", הכפתור "היכנסו לסלון" והתווית "הדלת זמנית". בתחתית כפתור לכל חדר: כניסה, סלון, ופינת אוכל וחדר שינה עם "בקרוב".
   - **התנועה:** דחיפה איטית של 2% ב-10 שניות, כמו שהמעצב כתב.
2. **הכניסה (1.2 ש').** הפתח גדל עד שהקיר יוצא מהמסך. בטלפון המצלמה מסתובבת בזמן הזה מהחלון אל הספה. הפריים האחרון הוא החדר הריק בדיוק.
3. **החשיפה, "מה כאן למכירה".** שלושה מושגים, שמחליפים בלי טעינה מחדש:
   - **B, סריקת עומק (ברירת המחדל, המלצת המעצב):** מישור אור נכנס לעומק החדר. קו המתאר של כל מוצר נדלק כשהמישור מגיע אליו, והמוצר מתמלא. לכל מוצר טבעת קטנה, תווית (שם ומחיר) ומונה "פריטים 9/13". בסוף: "13 פריטים · 26% מהחדר".
   - **A, פרץ (הרעיון של הבעלים):** החדר מעט עמום. כל מוצר נכנס מהנקודה שלו עם טבעת פליז, מטשטוש לחדות, מהכבד לקל. האור עולה עם המוצרים, ובסוף כל הצלליות מהבהבות כגוון אחד.
   - **C, הדגשה:** החדר מלא. כל מה שאינו מוצר יורד ל-35% בהירות, והמוצרים נשארים כמו שהם, עם קו מתאר חם.
4. **מנוחה.** על כל מוצר עיגול קטן. התוויות מתקפלות אחרי 0.8 ש'. אחרי 6 ש' בלי מגע מופיעה טבעת אחת על התמונה.
5. **תקריב וגלגל.** נגיעה במוצר או בעיגול שלו: המצלמה נכנסת (1.0 ש'), והגלגל עולה 0.15 ש' לפני שהיא נוחתת. הגלגל יושב **מתחת** למוצר, כך שרואים את המוצר בסביבה שלו.
   - **ההחלפה (0.45 ש'):** ‏S1 "מגב סריקה" (ברירת המחדל), ‏S2 "מהמתאר" או S3 "הרמה והנחה". ‏S3 פועל רק על אגרטל, קערה, פמוטים, עציץ וסל; בשאר העמדות רץ S1.
6. **מעבר סגנון, מודרני חם ↔ נורדי.**
   - **Y1, "פירוק והלבשה" (כ-3.0 ש'):** המוצרים נאספים, הבית מתחלף מהקיר האחורי קדימה, והמוצרים של הבית הבא נכנסים.
   - **Y2, "גל חומר" (1.2 ש'):** גל אחד מהחלון לאורך הרצפה, ומאחוריו הבית הבא כולו.
   - **הבית הנורדי:** השכבות הזמניות שיש לו היום, מסומן "שכבות זמניות". אין בו נקודות ואין גלגל.
7. **חזרה לדלת:** הכפתור "כניסה". המוצרים נאספים, והקיר נסגר סביב הפתח.

## איך פותחים
- **באתר (הבנייה עם הדגל):** `cd site && npm run build && npm run preview`, ואז `http://127.0.0.1:8788/tour/`.
- **ב-Artifact:** `cd site && npm run preview:artifact`. המנהל מפרסם את `site/dist-artifact/`. המסך הראשון הוא הדלת.
- **"בקרה זמנית"** (בפינה): חשיפה (פרץ / סריקת עומק / הדגשה), החלפה בגלגל, מעבר סגנון, "בדרך לחדר" (בית ריק / בית מלא) ו"הצגה מחדש". מתחת מופיעה שורה עם קצב הפריימים של האפקט האחרון.
- **בכתובת:** `?fx=a|b|c`, ‏`?sw=s1|s2|s3`, ‏`?st=y1|y2`, ‏`?way=empty|full`. ‏`?skip=1` מדלג על הדלת (לבדיקות).

**מה אפשר להסיק, ומה לא:**
- **אף אפקט לא מחזיק כאן 60 יציב, וגם הייחוס שעבר QA לא.** היעד של המעצב ("אין שני פריימים שנפלו ברצף") **לא הוכח ולא הופרך** בספרינט הזה.
- **מה שכן עובר לטלפון אמיתי:**
  - **זמן הסקריפט לפריים:** עד 0.9 מ"ש בממוצע במחשב, ועד 1.5 מ"ש בטלפון עם מעבד מואט פי 4. הפריים הגרוע ביותר: 15.3 מ"ש (חשיפה A, בטלפון). התקציב לפריים הוא 16.7 מ"ש.

- **מה עשיתי כדי שלא יגמגם:**
  - רק המלבנים של המוצרים שזזים מורכבים מחדש, ורמות ה-mip נבנות רק עבורם.
  - תוכנית התצוגה נבנית לפי הצורך: פריים של מנוחה או של מצלמה הוא טקסטורה אחת. זה לבדו העלה כאן את התקריב מ-28 ל-53 פריימים לשנייה.
  - טקסטורות עולות לכרטיס אחת-אחת, ואף פעם לא באמצע אפקט.
  - אין קריאה חזרה מהכרטיס באמצע אפקט.
  - התוכניות מקומפלות מראש.
- **איך סוגרים את הסעיף:**
  1. **על הטלפון של הבעלים:** ב"בקרה זמנית" מופיעה אחרי כל אפקט שורה כמו `reveal-b: 60 fps, 0 long frames of 132`.
  2. **על מכונה עם GPU:** `HD_GPU=1 npx --no-install tsx tools/mock1-fps.ts <out>`. במצב הזה הכלי נכשל אם אפקט כלשהו מפיל שני פריימים ברצף.
