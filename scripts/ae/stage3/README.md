# שלב 3 של ריצת AliExpress בהיקף גדול (אופליין)

2026-10-11. הסקריפטים שבעזרתם דורגו 1,457 המוצרים המפורטים של הסלון, פינת האוכל וחדר ההורים בלי קריאות API (מהמטמון ב-data/sources/aliexpress/).
- `prep.py`: עלות נחיתה (שער 3.3), רצועת מחיר, רווח לפי נוסחת הסטודיו, בחירה מחדש של ה-SKU שמתאים לחדר.
- `shortlist.py`: רשימה קצרה של עד 8 לכל עמדה × סגנון.
- `sheets.py`: גיליונות תמונות לבדיקה בעין.
- `reports.py`: הקבצים ב-data/leads/aliexpress/deep-2026-10/ ו-scale-2026-10/*.md.
- `cards.py`: כרטיסים דרך `ds.py --offline card`.
הסקריפטים נכתבו לריצה אחת; נתיבי הקלט והפלט שלהם הם בתיקיית עבודה זמנית, ולכן לפני הרצה מחדש צריך לעדכן אותם. משלוח ל-SKU שהוחלף הוא הערכה; רשימת `ds.py freight` לאימות נמצאת ב-data/leads/aliexpress/scale-2026-10/README.md.
