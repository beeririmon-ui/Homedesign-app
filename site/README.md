# site/: החנות (אפשרות ג')

האתר: Preact, ‏Vite ומנוע WebGL2. השרת: Cloudflare Worker (Hono) עם D1 ו-Queues.
הארכיטקטורה המלאה, ההחלטות הפתוחות והסביבות מתוארות ב-[`docs/architecture.md`](../docs/architecture.md).

## דרישות

- Node 22.12 ומעלה.
- כל השאר מקומי: לא צריך חשבון ולא צריך מפתח.

## הרצה מקומית

```bash
cd site
npm install
npm run dev        # בונה קטלוג ומדיה זמנית, מאפס D1 מקומי, ומריץ את Vite ‏(http://127.0.0.1:5180) ואת ה-Worker ‏(8787)
```

- בפעם הראשונה נוצר `api/.dev.vars` עם סוד מקומי אקראי ל-mock. הקובץ ב-gitignore.
- התשלום מדומה (`/mock-pay/...`), וגם הספק מדומה.

- משתמש ב-Chromium שב-`/opt/pw-browsers/chromium`. בסביבה הזו לא מריצים `playwright install`.
- במחשב אחר מגדירים `PW_CHROMIUM=<נתיב>`.
- ה-e2e מריץ `npm run preview` בעצמו, אחרי `npm run build`.

## מה נמצא איפה

- `shared/`: סכמות zod, תמחור (`pricing.ts`, אותה נוסחה כמו בסטודיו), חתימת webhook.
- `api/`:
  - `src/routes/`: ‏public, ‏payments ו-admin.
  - `src/lib/`: ‏payments ו-suppliers (ממשקים, כרגע mock), ‏fulfillment (צרכן התור) ו-access.
  - `migrations/`: הסכמה של D1.
  - `scripts/seed.ts`: מהקטלוג אל SQL.
- `web/`:
  - `src/engine/`: מנוע השכבות. הסדר לפי z מ-`data/slots`. הצל ב-multiply והאור ב-screen. מצלמה, זום עם פרלקסה, cross-fade של 0.3 שניות לווריאציה ושל שנייה לסגנון, ורצף פריימים.
  - `src/components/`: החדר, הגלגל והמעברים.
  - `src/pages/`: העמודים.
- `tools/`:
  - `build-catalog.ts`: מהריפו אל הקטלוג.
  - `make-temp-assets.ts`: תמונות זמניות בשמות הסופיים.
  - בדיקות תקציב ו-Artifact.
- `e2e/`: בדיקות Playwright.

- הנתיבים כבר סופיים. כשיהיו נכסים סופיים שעברו QA, מחליפים קבצים ולא קוד.

## Artifact (תצוגה מקדימה לפרסום)

```bash
npm run preview:artifact     # dist-artifact/: index.html ותיקיית media/ (WebP), ובדיקת מגבלות
npm run screens:artifact     # צילומים ב-screens/artifact-{1280,400}-*.png
```

- אין doctype, ‏html, ‏head או body.

- הניווט בזיכרון, בלי hash.
- העגלה וההזמנות נשמרות ב-localStorage, עם try/catch.

## החדר: וריאציות, נקודות מוצר ומעבר T-E0 (תיקונים 2026-10-09, חוקי הסטודיו ו.4–ו.6)

הבדיקה: `npm run preview:artifact`, ואחריו `npm run screens:room`. הצילומים וגיליונות ההשוואה נשמרים ב-`screens/`, ‏`before-*` הם המצב שלפני התיקון.

### החלפת וריאציה בלי כתמים (סבב 2, 2026-10-10)

**השורש:** השכבות הזמניות נחתכו לפי מסכה מנוחשת, ולא לפי צורת המוצר: "שונה מצבע הרקע המקומי" (objectness) בתוך מלבן העמדה. על חפצים בהירים מול קיר בהיר המסכה כללה כתמים מהקיר, מהספה ומהשולחן, והחמיצה חלקים מהמוצר. הצביעה מחדש צבעה את הכתמים האלה, וזה ה"אוברליי". הבדיקה הקודמת מדדה מחוץ למלבן, ולכן לא ראתה אותם. סיבה משנית: אלפא של AVIF מאבד (lossy) יוצר צלצול (ringing) עדין סביב המוצר.

**התיקון:**

- `tools/temp/make-masks.py` (‏OpenCV): קו מתאר של כל מוצר שסומן ביד על הפריים (`tools/temp/living-room.masks.json`), ועידון של GrabCut רק ברצועה צרה סביב הקו. מוצרים שלפניו (`behind`), נרות, השולחן והכורסה מוצאים מהמסכה. הפלט, `tools/temp/masks/living-room/*.png` ו-`outlines.json`, נשמר בריפו, ולכן ה-build לא צריך Python.
- `make-temp-assets.ts`: האלפא היא הצללית (קצה מוחלק של כפיקסל אחד), והצבע "נקי" (decontaminated): כל פיקסל עם אלפא גדולה מ-0 נושא את צבע המוצר. שכבות המוצר הן WebP עם אלפא lossless, ולא AVIF.
- המנוע: שכבות המוצר נטענות כ-WebP. ה-crossfade ממילא משנה רק את מה ששונה בין שתי הקומפוזיציות.

**הבדיקה** (`e2e/swap-diff.spec.ts`, חלק מ-`npm run e2e`): לכל עמדה ולכל וריאציה, במצב מנוחה וגם בזום של הגלגל, צילום מסך לפני ואחרי. ΔE2000 נמדד מחוץ לצללית (אלפא > 0.5 של שתי הווריאציות, ועוד 3 פיקסלים של השכבה). תנאי הקבלה: אפס פיקסלים עם ΔE ≥ 1. מפות diff וצילומי לפני ואחרי נשמרים ב-`assets/qa/swap-diff/`.

### נקודות מוצר (2026-10-10)

- במנוחה: סימן קטן אחד לכל מוצר, בנקודה העמוקה ביותר בתוך הצללית (`anchor` בסצנה). כך הסימן יושב על המוצר עצמו, ולא באמצע בין שני חלקים שלו.
- הסימנים לא חופפים: מרחק של 48px לפחות בין מרכזים. ה-`<button>` הוא יעד של 46px.
- בריחוף, במגע ובפוקוס: קו המתאר של המוצר עצמו (`outline` בסצנה, מתוך האלפא) בקו בהיר עדין, עם הילה חמה. גם ריחוף ולחיצה על המוצר עצמו פותחים אותו. הכפתור נשאר הפקד הנגיש.
- אין פעימה. עם `prefers-reduced-motion` אין מעברים.
- צילומים: `e2e/hotspots.spec.ts` → `assets/qa/hotspots/`.

### סט או יחידה (P1) ותקנים (D9)

- **N** = `sell_qty`: מ-`data/economics/products.json`, או לפי הכלל של הסטודיו (`sellQtyDefault`, העתק של `sell_qty_default` ב-`studio/build.py`, ובדיקה שמשווה ביניהם).
- כש-N > 1 מופיע בורר נגיש (radiogroup) בדף המוצר ובגלגל: "סט של N" (ברירת המחדל) או "יחידה אחת".
- מחיר הסט הוא `retail_ils`. מחיר יחידה נלקח מ-`unit_retail_ils`. אם אין, הוא **מחיר משוער** (`unitPriceEstimateIls`): ceil(סט / N × 1.15), מעוגל מטה ל-…9.
- העגלה, ה-API, ‏D1 (`cart_items.pack`, ‏`order_items.pack`) וההזמנה נושאים `pack: 'set' | 'unit'` ואת הכמות. הספק מקבל qty × `unit_sell_qty`.
- **תקנים ובטיחות:** מתוך `safety` בכרטיס (`shared/src/safety.ts`). מוצגות רק טענות שיש להן ערך. `source` לא נחשף, וקישור לתעודה מוצג רק אחרי אימות.

### מעבר T-E0 (כניסה ← סלון)

הקוד: `web/src/components/Transition.tsx`, ‏`engine/sequence.ts`, ‏`RoomEngine.arrive`.

1. מעבר רך קצר מהעמוד לפריים הראשון.
2. **הליכה:** הרצף מתנגן עם האצה, בלי האטה בתוך הצילום. יש מיזוג בין פריימים ושובל תנועה עדין שגדל עם המהירות.
3. **נעילת סוף:** כשהצילום עוד בתנועה, השכבה מתמוססת לתוך ה-M0 המורכב. במקביל, המנוע מטיס את המטר האחרון כ-dolly:
   - פרלקסה לפי `depth.480`: הקרוב נע יותר מהקיר האחורי.
   - האטה (ease-out) וטשטוש תנועה רדיאלי שדועך עם המהירות.
   - הנחיתה מדויקת על מצלמת המנוחה.

**הבדיקה:** `screens:room` מצלם את המעבר בהילוך איטי ×10, ובודק:

- **ההפרש בין הפריים האחרון לבין M0 המורכב במנוחה:** 0 פיקסלים מעל 12 רמות.
- **רציפות המצלמה:** המצלמה בסוף זהה למצלמת המנוחה (הפרש 0). הצעד הגדול ביותר בעשירית האחרונה הוא בערך 1e-5, מול 3e-2 בהתחלה, אז אין קפיצה במיקום או בקנה מידה.

**מגבלה זמנית:** צילום ההליכה הזמני (`prototype/assets/frames/entrance`) נגמר בחדר בגאומטריה ישנה. לכן בהתמוססות רואים לרגע שתי תמונות שונות. עם הנכסים הסופיים, אותו קוד ימזג בין תמונות זהות.

### מה motion-agent צריך למסור לגרסה סופית של T-E0

| נכס               | דרישה                                                                                                                                                                                                                                                                                                         |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| סרטון T-E0, נורדי | הפריים האחרון זהה ל-M0. אותה מצלמה (מיקום, yaw, FOV ו-shift כמו M0 ב-`docs/skeleton-spec.md`), אותה תאורה, ואותן ברירות מחדל של המוצרים. ההפרש מול ה-shell של M0 קטן מ-2 רמות ב-99.9% מהפיקסלים. הסרטון מתחיל בפריים H0 (yaw 12) ועובר ב-pan ל-H0x ואחר כך ב-dolly ישר (E0). המשך 2.2–2.6 שניות, 30fps, ‏16:9 |
| רצף פריימים       | `media/transitions/T-E0/nordic/<w>/NNN.webp`, מ-001, ברוחב 1280 (כמו היום). את ההמרה עושה `tools/make-temp-assets.ts` מתוך המקור שב-`assets/manifest.json`                                                                                                                                                    |
| מפת עומק ל-H0     | `media/rooms/hall/nordic/H0/depth.480.webp`: גווני אפור, 480×270, ‏1 (לבן) הכי קרוב ו-0 הכי רחוק, מיושרת פיקסל לפיקסל לפריים H0. משמשת לפרלקסה ביציאה מהכניסה ובחזרה אליה                                                                                                                                     |
| מפת עומק ל-M0     | אותו פורמט, ‏`media/rooms/living-room/nordic/M0/depth.480.webp`. היום היא סינתטית (מישורי החדר ומלבני העמדות)                                                                                                                                                                                                 |
| QA                | qa-agent מאשר את הפריים האחרון מול M0, ואת יישור מפות העומק, לפני שהנכסים נכנסים לאתר                                                                                                                                                                                                                         |

כשהנכסים יגיעו, מחליפים קבצים ולא קוד: `HAND_AT` ו-`HANDOFF` ב-`Transition.tsx` נשארים. ההתמוססות פשוט תהיה בין תמונות זהות.
