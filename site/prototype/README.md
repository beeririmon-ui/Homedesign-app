# אב-טיפוס: חוויית הסלון הנורדי

אב-טיפוס לבדיקת החוויה והאנימציות, לפני רינדור השכבות האמיתיות. **לא** הנכסים הסופיים.

- החדר, חלל הכניסה, 3 וריאציות של כיסוי הספה ו-3 תמונות הגלגל רונדרו ב-var2 (nano-banana-2 4K/2K, remove-background), 2026-09-28.
- כל וריאציה היא כרגע תמונת חדר שלמה (עריכת image-to-image), ולא שכבה שקופה כמו במפרט. באתר האמיתי כל וריאציה תהיה שכבה.
- ההליכה מהכניסה היא אנימציה בקוד (זום לתוך הפתח ומעבר רך), כי סרטון ה-var2 לא נוצר: חסרו קרדיטים.
- המוצרים והמחירים לדוגמה בלבד. הם לא לידים אמיתיים.

פותחים את `index.html` דרך שרת מקומי (למשל `python3 -m http.server`).
